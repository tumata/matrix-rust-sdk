The Apple XCFramework built by `cargo xtask swift build-framework --release` is now compiled with LTO. Only the FFI symbols stay global in `libmatrix_sdk_ffi.a`, so apps can dead strip the rest, and the linked code is ~26% smaller for an app that links it into its executable, and ~43% smaller when it is linked into a dynamic framework. The `--sequentially` option is removed, as the targets are now always built one after the other.
